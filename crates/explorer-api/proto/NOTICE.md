# Vendored protobuf definitions

`messages.proto` and `rpc.proto` are copied unchanged from
[rusty-karlsen](https://github.com/karlsen-network/rusty-karlsen)
(`rpc/grpc/core/proto/`, commit `959dc2af5b5aae56bbcc314732ccbdcb9c46d170`). They define the karlsend gRPC
interface this API uses to read blocks from the node.
